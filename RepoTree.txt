Production notes

- Production source of truth is the root CMake project and `src/`; `external/` supplies the configured vendored libsodium source. `packaging/` and `cmake/` define installation contents and package layouts.
- Packaged binaries under `dist/` and `release/windows/` are generated copies. CMake install/CPack produces platform ZIPs; the PowerShell scripts assemble Windows portable and single-file packages, and the installer definitions produce Windows installers. Release signing is a separate packaging step.
- The CLI is the base application. Qt GUI and WinFsp mount support are optional; WinFsp is Windows-only. The single-file portable executable is Windows-only. Linux/macOS and Windows release archives are separate platform/architecture builds. The PBA code is a lab prototype and is not included in this production map.
- Build directories, tests, local caches, and mutable per-user/runtime configuration are intentionally omitted. The local `dist/` directory contains release outputs; its runtime configuration file is omitted from this inventory.
